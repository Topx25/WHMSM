2 Install & license activation

1
Customer receives the license key by email / WhatsApp (auto-sent on serial creation), with the install one-liner.
2
Runs the installer — curl -A "…SafetyMonitorPro/installer" …/install.sh | bash -s -- <KEY>
Custom UA bypasses Cloudflare; plain curl is blocked.
3
Installer computes the server identity — main IP (/var/cpanel/mainip) + hardware fingerprint sha256(machine-id|hostname) → POST /api/download.
4
License server validates & binds — checks key (not expired/suspended/tampered), binds on first download (ip+host+fingerprint), enforces single-download, then streams the obfuscated tarball + X-Smpro-SHA256.
5
Installer verifies & deploys — checks SHA, extracts, registers the WHM addon (icon + ACLs + entry URL).
6
First open → activation — License page → POST /api/check → server returns an RSA-signed verdict (status, expiry, features[], bound ip/fp, signed timestamp, feat_key, pair_key). Plugin verifies the signature against the pinned public key & caches it in state.json.

5 License enforcement & anti-tamper

Transport outagereversible
License server unreachable → 48h graduated grace (banner escalates, heavy workers pause) → keeps running, auto-recovers on reconnect.
Commercial stop (expired / suspended / revoked)reversible
A real "no" for 48h → whole plugin goes dormant (UI locked, workers stop). NOT uninstalled — renewing clears it automatically.
Tamper (hosts-blackhole + no valid signature)destructive
Immediate silent full-lock (every page) → after 24h → self-uninstall, unless the operator issues a server-side reset. Admin is alerted (WhatsApp + email); a dead-man cron is the backstop.
Pairing beacon (rolling per-license code)reversible · opt-in
A disguised rolling code proves possession of a per-license secret. Sustained mismatch → admin-reasoned reversible stop (self-heals on a valid beacon; operator can Re-pair / rotate the secret).
Root-adversary hardening: grace measured from the server-signed timestamp (not the local clock) · monotonic clock guard (anti-rollback) · in-process integrity manifest (patching one gate doesn't disable protection) · server-side clone-thrash detection. Honest ceiling: a self-hosted plugin on customer-root can still be patched at the PHP level — the absolute fix is a bytecode encoder (ionCube).
