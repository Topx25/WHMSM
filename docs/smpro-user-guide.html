1 Introduction

Safety Monitor Pro (SM Pro) is a single WHM plugin that gives a hosting administrator a live, actionable view of server health and security — and the one-click tools to act on it.

Real-time server health, load & processes
Firewall (CSF/LFD) status & controls
Intrusion & web-attack monitoring
Forensics / malware audit per account
Outbound spam & phishing defense
Site Doctor — detect & auto-fix down sites
Server Tune-up with an optimization score
WhatsApp / Telegram / email alerts
AI-assisted diagnosis & fixes (bring your own key)
Manage many servers from one Hub

2 Requirements

A server running WHM / cPanel (AlmaLinux, CloudLinux, Rocky or Ubuntu)
Root access (the installer runs as root)
Outbound HTTPS to the license/update server
A valid license key (from your purchase email / WhatsApp)

3 Installation

You receive your license key and a one-line installer by email / WhatsApp the moment your serial is created. As root, paste it into your server's terminal:

curl -fsSL -A "Mozilla/5.0 …SafetyMonitorPro/installer" https://<license-host>/install.sh | bash -s -- YOUR-LICENSE-KEY
  • The installer reads your server's main IP and a hardware fingerprint and requests your signed copy of the plugin.
  • The package is verified (checksum) and extracted, and the WHM plugin is registered automatically.
  • Open WHM → Plugins → Safety Monitor Pro — you're taken to the License page to finish activation.
Tip: the installer is tied to your key + this server. Each key installs on one server; contact support to move a license to a new machine.

9 Site Doctor

Site Doctor checks a domain end-to-end (DNS → HTTP → redirects) and, when a site is down or stuck in a redirect loop, proposes — and can apply — a fix. It un-hardens locked files first, applies fixes incrementally, and re-checks until the site is up.

How to use

  • Enter or pick a domain → Site Doctor runs the checks.
  • Review the diagnosis and the proposed fixes.
  • Click Fix it — fixes are applied incrementally and verified; everything is reversible.

15 FAQ & support

Can I move my license to another server?

Each key is bound to one server. Contact support to release and re-bind it to a new machine.

Will applying a fix break my server?

No — every apply is backed up first, validated, and reversible. Access-risk changes (SSH/firewall) always require explicit confirmation.

What happens if the license server is briefly unreachable?

Nothing — the plugin keeps running on a grace period and recovers automatically when the connection returns.

How do I get help?

Use the support contact from your purchase. Have your license key and server hostname ready.
